## 2. Table: `activities` 

Notes:
- Primary Key: 
  - id (generated by Postgres)
- Unique Constraint:
  - Strava Activity ID
- NOT NULL:
  - Activity Date
  - Elapsed Time
  - Distance 
  - Moving Time
- Timestamps to be stored as UTC

Table: activities

| DB column | Source | DB type | Null? | Constraints | Notes |
|---|---|---|---|---|---|
| id | (generated) | BIGINT identity | No | Primary key | Generated by Postgres |
| strava_activity_id | Activity ID | BIGINT | No | Unique | Prevents duplicate loads |
